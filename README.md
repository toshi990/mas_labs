# Складская доставка

Консольная многоагентная система: диспетчер, склады и курьеры.
Требуется Python 3.10 или новее. Сторонние библиотеки не нужны.

## Запуск

Распаковать архив и открыть папку warehouse_mas в PyCharm.
Запустить main.py или выполнить из папки проекта:

```bash
python3 main.py
```

На старте вводятся параметры складов, курьеров и заказов.
Enter оставляет значение по умолчанию. Один шаг равен одной минуте.

## Меню

1 — состояние складов и курьеров.
2 — один шаг с выводом сообщений.
3 — несколько шагов.
4 — заказы.
5 — последние сообщения.
6 — выполнить все заказы.
7 — добавить заказ.
8 — сохранить трассу в output/console_trace.json.
0 — выход.

Для знакомства оставить начальные параметры по умолчанию, выполнить один
шаг через пункт 2, посмотреть состояние через пункт 1, затем выбрать пункт 6.
Все 10 заказов должны быть доставлены.

## Файлы

main.py — запуск.
mas/console.py — ввод, меню и вывод.
mas/model.py — агенты, заказы, сообщения и шаги модели.
mas/config.py — параметры и ограничения.
mas/network.py — карта дорог и поиск пути.
mas/__init__.py — пакет модели.
