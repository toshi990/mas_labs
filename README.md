# Лабораторные работы по теории многоагентных систем

Многоагентная система распределения заказов и координации курьеров при доставке со складов.

В системе работают диспетчер, склады и курьеры. Через консоль можно задавать параметры, выполнять моделирование по шагам и просматривать сообщения агентов.

## Лабораторные работы

| Работа | Содержание | Инструкция |
| --- | --- | --- |
| ЛР1 | Спецификация и базовая реализация многоагентной системы доставки | [lab1/README.md](lab1/README.md) |
| ЛР2 | Сравнение централизованного назначения венгерским алгоритмом, контрактной сети и аукциона заявок | [lab2/README.md](lab2/README.md) |

Подробные описания параметров, меню и порядка выполнения находятся в README соответствующих лабораторных.


## Запуск

Команды выполняются из корня репозитория.

### Лабораторная работа №1

```bash
python3 -m lab1.main
```

После запуска вводятся параметры складов, курьеров и заказов. Enter оставляет значение по умолчанию.

### Лабораторная работа №2

```bash
python3 lab2/main.py
```

Доступны пошаговая симуляция, сравнение трёх механизмов на одинаковых заказах и серия экспериментов.

## Эксперименты ЛР2

Из корня репозитория:

```bash
cd lab2
python3 run_experiments.py
```

Результаты сохраняются в `lab2/results/lr2/`.

## Тесты ЛР2

Из папки `lab2`:

```bash
python3 -m unittest discover -s tests -v
```
